Miniprojeto DevOps com IA Generativa
Objetivo
Demonstrar como a IA Generativa pode auxiliar no diagnóstico de falhas em pipelines CI/CD.

Tecnologias
Python
Pytest
GitHub Actions
ChatGPT/Copilot
Falha Encontrada
ZeroDivisionError: division by zero

Análise com IA
A IA identificou que o erro ocorreu devido a uma tentativa de divisão por zero e sugeriu tratamento da exceção.

Resultado
Após aplicar a correção sugerida e validar manualmente o código, o problema foi resolvido.
